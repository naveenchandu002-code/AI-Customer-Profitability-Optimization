# Resume Project Bullets

## Project Title

**Customer Profitability & Decision Optimization Platform**

### McKinsey / Business Analyst Version

- Built an end-to-end customer decisioning platform for **10,127 credit-card customers**, combining **Python, SQL, XGBoost, SHAP, and Power BI** to translate customer behavior into data-driven retention and growth decisions.
- Developed an **out-of-fold XGBoost churn model** and customer-value framework, then converted predictions into customer-level economic decisions; identified **229 customers with positive modeled retention economics** instead of targeting all high-risk customers.
- Built a **budget-constrained optimization engine** that selected the highest-value retention targets; under a **$10,000 modeled budget**, selected 100 customers and generated **$5,387 modeled incremental value (53.87% modeled ROI)**, outperforming random targeting across tested budget scenarios.

## Indus Insights / Analytics Version

- Analyzed **10K+ credit-card customers** using Python and SQL to identify churn patterns, customer-value segments, engagement signals, and economically attractive retention opportunities.
- Implemented **XGBoost + SHAP + out-of-fold prediction** to estimate churn risk and explain key behavioral drivers, then integrated customer value and intervention economics into a multi-stage decision engine.
- Designed **budget optimization and sensitivity-analysis workflows** and translated results into an executive **Power BI dashboard** for customer targeting, expected value, ROI, and retention prioritization.

## Important Interview Note

All financial outcomes are **modeled scenario estimates**, because the public dataset does not contain actual bank revenue, servicing costs, campaign-response outcomes, or retention-offer costs.
